## atb sketch install

Download the sketchlib binary (Linux/macOS only)

### Synopsis

Download the sketchlib binary from GitHub releases and install it
alongside the atb binary. This is required for 'atb sketch query'.

Not available on Windows.

```
atb sketch install [flags]
```

### Examples

```
  atb sketch install
```
