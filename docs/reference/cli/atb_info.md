## atb info

Show detailed information for a sample

```
atb info <sample_accession> [flags]
```

### Examples

```
  # Show all available info for a sample
  atb info SAMD00000355

  # Look up by run accession
  atb info SRR11427802
```

### Options

```
  -h, --help   help for info
```

### Options inherited from parent commands

```
      --config string     config file (default $HOME/.atb/config.toml)

```
